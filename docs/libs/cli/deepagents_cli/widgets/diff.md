# `libs/cli/deepagents_cli/widgets/diff.py`

> Diff composition and display widget.

## Functions and classes

### `compose_diff_lines()`

Builds structured diff line data.

### `_compose_diff_content()`

Turns diff lines into styled renderable content.

### `EnhancedDiff`

Textual widget for displaying diffs.

## Gotchas

Diff rendering should stay stable inside approval layouts.
