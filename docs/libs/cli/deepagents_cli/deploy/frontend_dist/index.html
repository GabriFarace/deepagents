The generated frontend then reads that global to choose the assistant ID, app name, auth provider, and optional prompt chips. ## File contents ```html Deep Agent
``` ## Gotchas The placeholder script is matched by a regex in `bundler.py`; changing its shape requires updating `_FRONTEND_PLACEHOLDER_RE` at the same time.
