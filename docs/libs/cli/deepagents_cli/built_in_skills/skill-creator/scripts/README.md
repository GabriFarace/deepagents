# `libs/cli/deepagents_cli/built_in_skills/skill-creator/scripts/`

> Deterministic helpers used by the built-in `skill-creator` skill.

## Files

- [`init_skill.md`](./init_skill.md) documents the scaffold generator for a new
  skill directory.
- [`quick_validate.md`](./quick_validate.md) documents the lightweight
  `SKILL.md` structure validator.

## Notes

These scripts are part of the skill payload rather than the primary CLI command
surface. The CLI's user-facing `deepagents skills create` command is documented
separately in [`../../../skills/commands.md`](../../../skills/commands.md).
