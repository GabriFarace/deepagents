# `libs/cli/deepagents_cli/built_in_skills/skill-creator/`

> Built-in skill for designing, scaffolding, and validating other skills.

## Files

- [`SKILL.md`](./SKILL.md) quotes the full skill-creation guide and activation
  frontmatter.
- [`scripts/README.md`](./scripts/README.md) indexes the deterministic helper
  scripts bundled with the skill.

## Notes

The body of `SKILL.md` intentionally points to bundled scripts for repeatable
operations. The scripts can be executed without loading every implementation
detail into the model context.
